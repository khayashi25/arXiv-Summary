### [1] Measurements of the electron neutrino-argon differential cross section without pions in the final state in MicroBooNE
- **著者**: MicroBooNE Collaboration
- **リンク**:（出版済）https://arxiv.org/abs/2603.13593
- **掲載情報**: Phys. Rev. D 114, 032006 (12 August, 2026)
- **要約**: MicroBooNE の full Booster Neutrino Beam data、$1.3\times10^{21}$ POT を用いた、argon 上の $\nu_e$ charged-current 0π 終状態の微分断面積測定。電子と陽子の運動量・角度に加え、proton-electron opening angle など hadronic/leptonic system の相関も出している。DUNE/ICARUS/SBN 系で重要な $\nu_e$ interaction modeling の実データ制約で、lepton kinematics は多くの generator と概ね合う一方、hadronic system、特に proton angle に不一致が見える。ニュートリノ専門目線では今日一番読む価値が高い。
- **キーワード**: MicroBooNE, $\nu_e$-argon, LArTPC, 0π, cross section, generator tuning

### [2] NuOscProbExact: a fast, general-purpose code to compute exact two-, three-, and four-flavor neutrino oscillation probabilities
- **著者**: Mauricio Bustamante
- **リンク**:（査読状況不明・コード更新版）https://arxiv.org/abs/1904.12391
- **要約**: ニュートリノ振動確率を Hamiltonian の固有ベクトル対角化ではなく、SU(2), SU(3), SU(4) 生成子展開で厳密閉形式として計算するコード。2, 3, 4 flavor に対応し、真空・定密度 matter・piecewise Earth profile・NSI・Lorentz violation・sterile など、時間/位置に依存しない Hermitian Hamiltonian なら新しい solver を書かずに扱える。BSM neutrino fit で大量の Hamiltonian を掃く用途にかなり実用的。Majorana そのものではないが、sterile/非標準相互作用/ローレンツ破れ探索の計算基盤として有用。
- **キーワード**: neutrino oscillation, exact probability, sterile neutrino, NSI, Lorentz violation, public code

### [3] Missing-mass search in forward-proton-tagged dilepton events with the ATLAS detector
- **著者**: ATLAS Collaboration
- **リンク**:（出版済）https://arxiv.org/abs/2603.20837
- **掲載情報**: JHEP 07 (2026) 236
- **要約**: ATLAS Forward Proton spectrometer で outgoing proton を測り、$\gamma\gamma\to VX$ の missing mass を再構成する BSM 探索。$V$ は $e^+e^-$ または $\mu^+\mu^-$、$X$ は central detector に見えない成分として扱うため、$X$ の性質にあまり依存しない model-independent search になっている。2017 年 13 TeV, 14.7 fb$^{-1}$。100-900 GeV の narrow resonance 探索で有意な超過なし、95% CL 上限は signal model により 128-2.5 fb。invisible/hidden sector 探索として手法が面白い。
- **キーワード**: ATLAS, forward proton, missing mass, photon fusion, invisible particle, BSM

### [4] Contrastive Learning for Interpretable Anomaly Detection at Collider Experiments
- **著者**: Haoyi Jia, Sagar Addepalli, Julia Gonski
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.13652
- **要約**: HL-LHC 条件を想定した collider anomaly detection 手法 ORCA。既知 process 間の supervised contrastive learning で embedding を作り、その空間で autoencoder anomaly score を定義する。単なる「異常度が高い」だけでなく、embedding 上の template fit で anomalous sample がどの既知物理過程に近いかを解釈できる点が売り。BSM 探索では anomaly score が energy scale や multiplicity に引きずられる問題が大きいので、解釈可能性まで含めた設計は実験解析として重要。
- **キーワード**: anomaly detection, contrastive learning, HL-LHC, BSM search, interpretable ML

### [5] Unknown Unknowns: Model Misspecification in Machine Learning for Physics
- **著者**: Juan Cruz-Martinez, Carolina Cuesta-Lazaro, Alexander Held, Michael Kagan
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.13633
- **要約**: ML を simulation-trained / data-applied で使う物理解析における model misspecification の総説的議論。新物理探索では misspecification が「発見したいズレ」でもあり、精密測定では「吸収したい nuisance」でもある、という整理がよい。単一 diagnostic で正しさを保証するのではなく、複数診断・再学習・mitigation のループとして robust analysis を作るべき、という実験解析向けの実践論。ニュートリノ generator/systematics にも考え方はそのまま刺さる。
- **キーワード**: machine learning, model misspecification, robustness, systematics, anomaly search

### [6] Improved measurement of $C\!P$ violation in $B^{0}_{s} \to J/\psi\pi^{+}\pi^{-}$ decays
- **著者**: LHCb Collaboration
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.14119
- **要約**: hep-ex 新規投稿 1 本。LHCb Run 2 の 13 TeV, 6 fb$^{-1}$ を用いて、$B_s^0\to J/\psi\pi^+\pi^-$ の time-dependent CP asymmetry を更新。測定値は $\phi_s=-0.077\pm0.034\pm0.007$ rad、$|\lambda|=0.993\pm0.026\pm0.007$、$\Gamma_H=0.610\pm0.002\pm0.004\,\mathrm{ps}^{-1}$。過去測定との combination では $\phi_s=-0.046\pm0.031$ rad、他の LHCb 測定込みで $\phi_s=-0.041\pm0.017$ rad。SM と整合。flavor-sector BSM constraint として堅実だが、ニュートリノ/DM からは距離あり。
- **キーワード**: LHCb, $B_s$, CP violation, $\phi_s$, flavor physics

### [7] Optical Characterization Measurements of Commercial Polyvinyltoluene Scintillators for Accurate Geant4 Detector Modeling
- **著者**: Fergus Martin Huggins, Micah S. Johnson, Matthew Quinn Buckner
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.13710
- **要約**: BC-400/404/408/418/422/430 など市販 PVT scintillator の wavelength-dependent refractive index と bulk absorption length を 370-660 nm で測定。メーカー値や pure PVT 文献値からのズレが Geant4 光学 photon simulation に効き、BC-422 の validation では measured $n(\lambda)$ を使うと detected photon count が 7.2% 減る。検出器設計・calibration では地味だが重要な input data。ニュートリノ検出器の scintillator/optical model にも横展開できる。
- **キーワード**: PVT scintillator, optical properties, Geant4, detector simulation, calibration

### [8] Pairton: Iterative Reconstruction of Short-Lived Particles
- **著者**: Andreas Hermansen, Chris Scheulen, Tobias Golling
- **リンク**:（投稿予定: Phys. Rev. D）https://arxiv.org/abs/2608.14278
- **要約**: short-lived particle reconstruction を graph 上の masked prediction として定式化する Pairton の提案。decay product 間の adjacency matrix を反復的に予測し、pairformer 的な pairwise representation を動的更新する。fully hadronic $t\bar{t}$ で state-of-the-art performance を示す。collider 向けだが、複雑 topology の再構成を生成モデル的に扱う発想は、LArTPC event reconstruction や multi-particle final state の ML 解析にも参考になる。
- **キーワード**: particle reconstruction, graph ML, pairformer, masked prediction, top quark

### [9] Observation of several sources of $C\!P$ violation in $B^+ \to K^+π^+π^-$ decays
- **著者**: LHCb Collaboration
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.12614
- **要約**: $B^+\to K^+\pi^+\pi^-$ の amplitude analysis で、6 種類の CP-violating phenomena を初めて有意と判定。$B^+\to\rho(770)^0K^+$ の quasi-two-body CP violation を発見し、$B^+\to f_2(1270)K^+$ では amplitude level の CP violation を確立。さらに S-wave rescattering 領域や spin-3 resonance を含む崩壊、partial wave interference にも CP violation/evidence を報告。long-distance strong dynamics が CP 非対称を作る場として重要。
- **キーワード**: LHCb, CP violation, amplitude analysis, charmless B decay, long-distance QCD

### [10] Tracking the baryon number with nuclear collisions
- **著者**: STAR Collaboration
- **リンク**:（査読状況不明）https://arxiv.org/abs/2408.15441
- **要約**: baryon number が valence quark に 1/3 ずつ乗るのか、非摂動的な baryon junction が担うのかを、isobar nuclear collision と photonuclear collision で調べる STAR の測定。mid-rapidity の $B/\Delta Q$ と rapidity 方向の net-proton yield が、baryon number を valence quark に割り当てる model 予測と合わず、valence-quark picture を disfavor すると主張。hep-ex というより nucl-ex 寄りだが、baryogenesis 以来保存される量を実験的にどう追跡するか、という意味で基礎的に面白い。
- **キーワード**: STAR, baryon number, baryon junction, nuclear collision, QCD
