### [1] First Search for Quirks at the LHC with FASER
- **著者**: FASER Collaboration
- **リンク**:（ステータス不明）https://arxiv.org/abs/2607.26195
- **要約**: LHC で初めて quirk を直接探索した FASER 解析。quirk は SM 荷電と QCD 類似の infracolor 相互作用を持つ仮想粒子で、通常の LLP や heavy stable charged particle とは異なる、遅い荷電ペアとして現れる可能性がある。2022–2024 年の 13.6 TeV pp 衝突、積分ルミノシティ 186 fb⁻¹を使用し、シンチレータの電荷・タイミング情報で探索。背景ほぼゼロの領域で事象は観測されず、電荷 ±1、QCD color を持たない quirk について、infracolor confinement scale $300\,{\rm eV}<\Lambda<100\,{\rm keV}$ の広い範囲で弱スケール以上の質量を初めて除外。FASER の forward geometry と低背景を活かした、手法面でもかなり新しい BSM 探索。
- **キーワード**: FASER, quirk, infracolor, LLP, timing, BSM

### [2] SET-ANUBIS: a modular pipeline for ANUBIS long-lived particle sensitivity studies
- **著者**: Sofie Nordahl Erner, Anna Mullin, Théo Reymermier, Paul Swallow, Oleg Brandt for the ANUBIS Collaboration
- **リンク**:（ステータス不明）https://arxiv.org/abs/2607.26112
- **要約**: 提案中の ANUBIS 検出器に対する LLP 感度評価を、生成から検出器幾何・選別・cutflow 可視化まで一貫して扱う open-source Python framework。UFO model や外部 rate を入力に、崩壊幅・分岐比・寿命評価、Pythia8/MadGraph 実行、HepMC 読み込み、ATLAS cavern と ANUBIS tracking station の幾何、kinematic/isolation cut を処理する。物理ロジックと外部 generator/保存/可視化を分離する ports-and-adapters 設計、SQLite catalog、content-addressed store、JSON/HTML の selection trace など、LLP 感度研究の再現性をかなり意識した実装。新粒子モデル比較の基盤として有用。
- **キーワード**: ANUBIS, LLP, sensitivity study, simulation pipeline, reproducibility

### [3] Search for exotic Higgs boson decays H $\to$ $\mathcal{AA}$ with $\mathcal{AA}$ $\to$ $γγ$ in events with a semi-merged topology in proton-proton collisions at $\sqrt{s}$ = 13 TeV
- **著者**: CMS Collaboration
- **リンク**:（出版済: JHEP 07 (2026) 119）https://arxiv.org/abs/2601.00183
- **要約**: Higgs が軽い新粒子 $\mathcal{A}$ の対に崩壊し、それぞれが $\gamma\gamma$ に崩壊する exotic decay を探索。特徴は semi-merged topology、つまり一方の $\mathcal{A}\to\gamma\gamma$ が近すぎて単一 photon-like object として再構成され、もう一方は resolved diphoton として見える点。CMS Run 2 の 13 TeV、138 fb⁻¹を使用。データは SM 背景と整合し、$\sigma(pp\to H)\mathcal{B}(H\to\mathcal{AA}\to4\gamma)$ に 0.264–0.005 pb の 95% CL 上限を設定。特に $1<m_\mathcal{A}<5$ GeV では最も強い制限。軽い hidden-sector scalar/pseudoscalar 探索として重要。
- **キーワード**: CMS, exotic Higgs decay, hidden sector, photon-jet, BSM

### [4] Improved analysis of non-resonant Higgs boson pair production in the $b\bar{b}τ^+τ^-$ final state with $196$ fb$^{-1}$ of data collected at $\sqrt{s}$ = 13 TeV and 13.6 TeV with the ATLAS detector
- **著者**: ATLAS Collaboration
- **リンク**:（EPJC 投稿済）https://arxiv.org/abs/2607.26879
- **要約**: ATLAS による非共鳴 Higgs pair production, $HH\to b\bar b\tau^+\tau^-$ の更新解析。Run 2 の 140 fb⁻¹に加え Run 3 初期の 56 fb⁻¹を含む計 196 fb⁻¹を使用し、再構成と解析手法も改善。信号強度は $\mu_{HH}=2.6^{+1.4}_{-1.0}$ で SM と整合、背景のみ仮説に対する observed significance は 2.6σ。Higgs self-coupling modifier は 95% CL で $\kappa_\lambda \in [-3.4,1.6]\cup[5.5,10.1]$。直接 BSM ではないが、Higgs potential と EWSB の形を測る基礎量なので、将来の標準模型逸脱探索の土台として重要。
- **キーワード**: ATLAS, Higgs pair production, self-coupling, bbττ, Run 3

### [5] Anomalies in Hadronic $B \to VV$ Decays
- **著者**: Bhubanjyoti Bhattacharya, Marianne Bouchard, Alexandre Jean, David London, Ipsita Ray
- **リンク**:（ステータス不明）https://arxiv.org/abs/2607.27202
- **要約**: charmless hadronic $B\to VV$ 崩壊を flavor SU(3) 対称性の下で解析し、SM との大きな不一致を報告。$B\to\rho K^*$ の isospin fit は問題ない一方、$B\to VV$ with $V\in\{\rho,K^*\}$ では 5.2σ、さらに $\phi,\omega$ を含めると 7σ 超の discrepancy と主張。理論入力は比較的少なく group-theoretical な解析だが、SU(3) breaking がどこまで吸収できるかは要検証。直接ニュートリノではないが、flavor sector の BSM hint としてはかなり攻めた内容。
- **キーワード**: B physics, flavor anomaly, SU(3), hadronic decay, BSM

### [6] Evidence for the rare decay $B^{+} \to \bar Λp μ^{+} μ^{-}$
- **著者**: LHCb Collaboration
- **リンク**:（出版済: Phys. Rev. Lett. 137 (2026) 051801）https://arxiv.org/abs/2601.06878
- **要約**: LHCb による希崩壊 $B^+\to\bar\Lambda p\mu^+\mu^-$ の探索。13 TeV、5.4 fb⁻¹のデータを用い、$m(\bar\Lambda p)<2.8$ GeV/$c^2$ の低質量領域で 3.5σ の evidence を観測。分岐比は $1.70^{+0.65}_{-0.56}({\rm stat})\pm0.17({\rm syst})\pm0.14({\rm ext})\times10^{-8}$。高質量領域では有意な信号はなく上限を設定。$b\to s\ell\ell$ 系の rare decay は BSM 感度が高く、baryonic final state のデータ拡張として価値がある。
- **キーワード**: LHCb, rare B decay, baryonic final state, flavor physics, PRL

### [7] Qubit-qubit-qutrit quantum correlations in $H \to f \bar f V$
- **著者**: Michał Banacki, Misaki Ohta, Abhyoudai S. Shaleena, Paweł Caban, Michał Eckstein, Kazuki Sakurai, Michael Spannowsky, Paweł Horodecki
- **リンク**:（ステータス不明）https://arxiv.org/abs/2607.26122
- **要約**: Higgs 崩壊 $H\to f\bar f V$、特に $h\to\tau^-\tau^+Z$ に現れる qubit-qubit-qutrit の量子相関を解析。tree-level spin state を使い、entanglement、Bell inequality violation、non-stabiliserness/magic を位相空間全体で調べる。実験論文というより量子情報×高エネルギー現象論だが、Higgs decay の spin correlation を量子相関 observable として扱う方向性は新しい。将来 collider で量子性を測る議論に関心があれば面白い。
- **キーワード**: Higgs, quantum correlation, entanglement, Bell inequality, tau

### [8] Automated NRQCD and NRQED simulations of quarkonium and leptonium production with P-wave states and physical-mass effects
- **著者**: Luca Maxia, Hua-Sheng Shao, Lukas Simon
- **リンク**:（ステータス不明）https://arxiv.org/abs/2607.26739
- **要約**: MadGraph5_aMC@NLO に非相対論的束縛状態生成を自動化する MadSONS module を拡張し、P-wave state と物理的な束縛状態質量効果を扱えるようにした論文。quarkonium/leptonium 生成の tree-level simulation に対し、軌道角運動量射影を dual numbers で実装し、phase space には momentum reshuffling を導入。応用例として LHCb の $J/\psi+\psi(2S)$ 生成データの記述を改善。BSM 直結ではないが、生成シミュレーションの自動化・精密化という意味で実験解析基盤に近い。
- **キーワード**: MadGraph, NRQCD, NRQED, quarkonium, simulation

### [9] Constraining $α$-cluster compactness in $^{16}\rm O$ and $^{20}\rm Ne$ at TeV energies using azimuthal anisotropy
- **著者**: Aswathy Menon Kavumpadikkal Radhakrishnan, Suraj Prasad, Neelkamal Mallick, Raghunath Sahoo, Gergely Gábor Barnaföldi
- **リンク**:（投稿済）https://arxiv.org/abs/2607.26758
- **要約**: LHC の軽イオン衝突で測る elliptic flow $v_2$ から、$^{16}$O と $^{20}$Ne の $\alpha$ cluster 構造の compactness を制限できるかを調べた研究。IP-Glasma+MUSIC+iSS+UrQMD による hybrid simulation を用い、Woods-Saxon 型と $\alpha$-cluster 型の密度分布を比較。特に OO 衝突では初期核構造の違いが centrality dependence や $v_2$ の peak に現れやすいと主張。高エネルギー重イオンを核構造プローブとして使う話で、ニュートリノ核反応とは別方向だが nuclear modeling に関心があれば接点はある。
- **キーワード**: light-ion collision, alpha clustering, elliptic flow, nuclear structure, LHC

### [10] Physics-Informed Global Extraction of the Universal Small-$x$ Dipole Amplitude
- **著者**: Si-Wei Dai, Fu-Peng Li, Long-Gang Pang, Guang-You Qin, Shu-Yi Wei, Han-Zhong Zhang, Wenbin Zhao
- **リンク**:（ステータス不明）https://arxiv.org/abs/2603.08008
- **要約**: small-$x$ dipole scattering amplitude $N(r,x_B)$ を、MV 型などの固定パラメトリゼーションを仮定せず、physics-informed neural network でグローバル抽出する研究。DIS の reduced total/charm cross section、exclusive $J/\psi$ photoproduction、運動量空間での positivity、collinearly improved BK evolution を同時に使う。従来 fit で問題になっていた total と charm channel の tension を緩和すると主張。hep-ex というより CGC/small-$x$ phenomenology だが、EIC や forward physics の基礎入力としては有用。
- **キーワード**: small-x, CGC, dipole amplitude, PINN, DIS
