## 注目論文

### [1] MANGO: An Autodiff Neutrino Oscillation Engine for Differentiable Analysis Pipelines
- **著者**: Pierre Granger
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.13429
- **要約**: ニュートリノ振動確率そのものではなく、その **微分可能性** を主役にした oscillation engine。真空、定密度、layered PREM、任意密度プロファイル、断熱太陽伝播に加え、NSI、3+N sterile、decoherence、non-unitary mixing まで front-end を用意。地球の 369 個の密度・電子比・shell radius パラメータに対する感度計算が、標準6振動パラメータの場合と同程度の reverse-mode overhead で済む、という設計が実験デザイン向き。検出器応答、event weighting、binning、likelihood まで gradient を通せるので、将来の atmospheric/long-baseline/solar 解析や Earth tomography の最適化にかなり刺さる。OscProb, NuFast-Earth と $10^{-9}$–$10^{-5}$ レベルで一致。
- **キーワード**: neutrino oscillation, autodiff, NSI, sterile neutrino, Earth tomography, differentiable analysis

### [2] Newtrinos.jl: A Julia Package for Global Analysis of Neutrino Data
- **著者**: Philipp Eller, David Schultheiß
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.12940
- **要約**: ニュートリノデータの global analysis 用 Julia package。physics model、experiment description、statistical inference を三層に分け、実験と理論モデルを自由に組み合わせる設計。likelihood だけでなく data-generating process と systematic uncertainty まで forward model として実装し、Frequentist/Bayesian 両方に対応。Julia 実装なので自動微分・並列化とも相性が良い。MANGO と同じく「ニュートリノ解析を微分可能・合成可能な統計モデルとして扱う」方向で、実験横断 fit や BSM hypothesis testing の基盤として注目。
- **キーワード**: neutrino global fit, Julia, automatic differentiation, likelihood, systematics

### [3] Axion-Like Particle Search with a Hybrid Cherenkov-Scintillation Detector
- **著者**: A.A. Aguilar-Arevalo et al.
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.12616
- **要約**: CCM200 の 10 ton 液体 Ar 検出器を使った、beam-dump 由来 ALP 探索の proof-of-concept。面白いのは物理結果そのものより、**hybrid Cherenkov-scintillation** の使い方。PMT の約80%を波長変換材で coat、20%を uncoated にして、ns timing と組み合わせて prompt Cherenkov 成分と Ar scintillation を分ける。ALP 由来の電磁相互作用に期待される topology と光時間構造から4つの observable を作り、likelihood-ratio classifier で steady-state background を抑制。$10^{-3}$ MeV $<m_a<10$ MeV で有意な excess はなし。ただし CCM120 より少ない exposure でも感度を上回っており、低エネルギー BSM 探索用の光検出技術としてかなり良い実証。
- **キーワード**: ALP, CCM, liquid argon, Cherenkov-scintillation, beam dump, BSM

### [4] Prospect of the NUCLEUS Experiment at Chooz for Coherent Elastic Neutrino-Nucleus Scattering and New Physics Searches
- **著者**: NUCLEUS Collaboration
- **リンク**:（査読状況不明・replacement）https://arxiv.org/abs/2603.24450
- **要約**: Chooz 原子炉近傍で gram-scale cryogenic calorimeter を使い、$\mathcal{O}(10~\mathrm{eV})$ recoil threshold で CEνNS を狙う NUCLEUS の感度予測。commissioning で見えている low-energy excess を data-driven に扱い、reactor power variation を使って signal/background を分離する likelihood framework が現実的。Technical Run の 7 g CaWO$_4$ でも CEνNS observation なしで BSM に競争的感度、Physics Run で LEE を抑えられれば 1年で 4.7σ observation、約20% precision、さらに最低 $Q^2$ 領域での weak mixing angle、neutrino charge radius、新 mediator 制限まで見込む。ニュートリノ標準相互作用測定と軽い新物理探索の両方で重要。
- **キーワード**: CEνNS, reactor neutrino, cryogenic calorimeter, weak mixing angle, neutrino charge radius, light mediator

### [5] Projected sensitivity of the ANUBIS detector to heavy neutral leptons
- **著者**: Martin Bauer et al. for the ANUBIS Collaboration
- **リンク**:（査読状況不明・replacement）https://arxiv.org/abs/2606.26862
- **要約**: ATLAS cavern ceiling を instrument する LLP 検出器 ANUBIS の HNL 感度予測。minimal Majorana HNL が単一 lepton flavor にだけ結合する仮定で、$m_N\simeq6.3$–6.4 GeV 付近に対し $|V_{1e}|^2=1.8\times10^{-8}$、$|V_{1\mu}|^2=1.9\times10^{-8}$ まで到達可能とする。HNL は seesaw/Majorana neutrino の実験的窓なので、ユーザー関心にかなり近い。ANUBIS は ATLAS interaction point から飛んでくる長寿命粒子の displaced decay を拾う設計で、MATHUSLA/FASER/CODEX-b などと相補的。SET-ANUBIS という flexible sensitivity framework を使っており、他の LLP model への再利用性も売り。
- **キーワード**: HNL, Majorana neutrino, LLP, ANUBIS, ATLAS, seesaw

### [6] Singlet-Doublet fermion origin of dark matter, neutrino mass and inverse first-order electroweak phase transition
- **著者**: Debasish Borah, Indrajit Saha, Sujit Kumar Sahoo, Narendra Sahu, Shashwat Sharma
- **リンク**:（査読状況不明・cross-list）https://arxiv.org/abs/2608.12483
- **要約**: scotogenic 型の radiative neutrino mass model に singlet-doublet fermion を入れ、DM、ニュートリノ質量、inverse first-order electroweak phase transition、重力波をまとめて扱う phenomenology。軽いニュートリノは簡単のため Dirac とし、右巻きニュートリノ、singlet scalar、2世代の $SU(2)_L$ singlet/doublet fermion を追加。残存 $Z_2$ で安定な中性 singlet-doublet fermion が DM になり、重い fermion の Higgs coupling が強いことで二段階の first-order phase transition を起こす。collider、direct detection、GW、CMB で検証可能な領域を議論。hep-ex としては実験論文ではないが、DM×neutrino mass×EWPT の統合モデルとして興味順は高い。
- **キーワード**: dark matter, radiative neutrino mass, scotogenic model, electroweak phase transition, gravitational wave

### [7] Laboratory constraints on peV-scale mass splitting between ordinary and sterile neutron states
- **著者**: N. J. Ayres et al.
- **リンク**:（査読状況不明・replacement）https://arxiv.org/abs/2608.12173
- **要約**: mirror sector を暗黒物質候補として考え、通常 neutron $n$ と mirror neutron $n'$ の oscillation を、両者が質量縮退していない場合まで含めて実験制限。$5~\mu\mathrm{T}<B<360~\mu\mathrm{T}$ の磁場を掃引し、有限質量差に対応する resonance 条件を探す。$0.3$–$22$ peV の質量差範囲で oscillation time constant におよそ 20 s までの exclusion。いくつかの領域では neutron-star cooling 由来の model-dependent bound より強く、mirror matter 系 BSM に対する実験制限として価値がある。ニュートリノではないが、sterile/mirror sector と暗黒物質関心には近い。
- **キーワード**: mirror neutron, sterile sector, dark matter, neutron oscillation, peV mass splitting

### [8] Fine-tuned Normalizing Flows for ALICE Zero Degree Calorimeter Fast Simulation
- **著者**: Emilia Majerz, Jacek Otwinowski, Witold Dzwinel, Jacek Kitowski
- **リンク**:（会議採択: PPAM 2026・cross-list）https://arxiv.org/abs/2608.12795
- **要約**: ALICE ZDC neutron detector response の fast simulation を Normalizing Flow で置き換える研究。full MC は高コストなので、imbalanced full dataset で pre-train し、$\gamma$, $n$, $\Lambda$, $K_S^0$, $\Sigma^+$ など粒子種ごとに fine-tune。単なる Wasserstein distance だけでは条件付き応答構造を見落とすため、conditional weighted MAE、dispersion ratio、Jaccard co-activation error という physics-motivated metric を導入している点が良い。検出器 simulation の高速化は LHC 系だけでなく、将来の大規模ニュートリノ検出器の surrogate modeling にも通じる。
- **キーワード**: detector simulation, Normalizing Flow, ALICE ZDC, fast simulation, ML

### [9] Observation of several sources of $C\!P$ violation in $B^+ \!\to K^+ π^+ π^-$ decays
- **著者**: LHCb Collaboration
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.12614
- **要約**: LHCb 2011–2012 の 3 fb$^{-1}$ データを使った $B^+\to K^+\pi^+\pi^-$ amplitude analysis。6種類の CP-violating phenomena を初めて有意と判定。$B^+\to\rho(770)^0K^+$ の quasi-two-body CP violation を発見し、$B^+\to f_2(1270)K^+$ では amplitude level の CP violation を確立。さらに elastic S-wave $\pi\pi$ rescattering 領域、spin-3 resonance を含む崩壊、$\pi\pi$ partial wave 間干渉でも CPV を報告。直接 BSM 探索ではないが、長距離強相互作用と CPV の標準模型基準を固める意味で、将来の model-independent BSM probe の土台になる。
- **キーワード**: LHCb, CP violation, amplitude analysis, B physics, long-distance QCD

### [10] Amplitude analysis of $B^+ \!\to K^+ π^+ π^-$ decays
- **著者**: LHCb Collaboration
- **リンク**:（査読状況不明）https://arxiv.org/abs/2608.12612
- **要約**: 同じ $B^+\to K^+\pi^+\pi^-$ 系の包括的 amplitude analysis。branching fraction と quasi-two-body CP asymmetry を測定し、特に支配的な $K^+\pi^-$ および $\pi^+\pi^-$ S-wave の記述を、isobar 近似に基づく解析モデル、K-matrix、quasi-model-independent 手法の3通りで比較。多くの intermediate state で最精密測定を与え、3手法の整合性も確認。新物理というより、強い相互作用の hadronic uncertainty を制御して flavor sector の precision test を改善する論文。
- **キーワード**: LHCb, B decay, amplitude analysis, S-wave, CP asymmetry, flavor physics
